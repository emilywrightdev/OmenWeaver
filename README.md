# OmenWeaver

OmenWeaver is a scalable predictive-modeling framework that utilizes auto-scaling components to optimize performance.

OmenWeaver is aimed at developers who need a straightforward, dependable solution.

## Installation

1. Clone the repository: `git clone https://github.com/minhokingkim/OmenWeaver.git`
2. Install required dependencies: `pip install -r requirements.txt`

## Configuration

OmenWeaver is configured through environment variables (see `.env.example`). Key options:
- **APP_ENV**: `development` or `production`.
- **PORT**: Port the server listens on.
- **LOG_LEVEL**: `debug`, `info`, or `error`.
